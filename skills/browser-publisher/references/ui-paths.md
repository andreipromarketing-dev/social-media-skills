# UI-пути публикации (заполняется при браузерных прогонах)

Формат записи: площадка → пошаговый путь с точными названиями кнопок/полей.
Пустой путь = ещё не верифицирован; первый прогон делает browser-publisher в режиме разведки.

## ВКонтакте (запасной путь, если нет API-токена)
- [ ] Открыть `https://vk.com/<сообщество_из_accounts.md>`
- [ ] Поле «Написать сообщение…» внизу ленты
- [ ] Вставить текст → проверить сворачивание
- [ ] 📎 → выбрать файл (фото)
- [ ] Стрелка у «Опубликовать» → «Опубликовать сейчас» / «Запланировать»

## MAX (max.ru) — ПУТЬ НЕ ВЕРИФИЦИРОВАН
- [ ] Разведочный прогон обязателен перед первой публикацией.

## Telegram (web.k.telegram.org) — для постов от личного аккаунта
- [ ] Открыть канал из списка чатов
- [ ] Поле «Сообщение» → вставить текст
- [ ] 📎 → файл
- [ ] Правый клик по отправленному сообщению недоступен до отправки; планирование — через удержание кнопки отправки (проверить версию web)

## TenChat (tenchat.ru) — ПУТЬ НЕ ВЕРИФИЦИРОВАН
- [ ] Разведочный прогон обязателен: найти кнопку создания поста, проверить хештеги и загрузку медиа.

---
После каждого верифицированного прогона: обновить соответствующую карту площадки и этот файл.

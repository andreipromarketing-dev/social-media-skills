# Crosspost Adapter — один текст → несколько площадок

## Критично при загрузке
Сразу к шагу 1. Не пересказывать этот скилл пользователю.

## Шаг 1. Получить исходник и список площадок
1. Если пользователь не вставил текст — попросить вставить (или указать файл/черновик).
2. Определить целевое ВК-сообщество (`nord21vek` / `vod_str` / `southspecialnetwork`) — из контекста, реестра `brand/accounts.md` или одним вопросом; тон берётся из `skills/social-media-ru/references/platform-playbook.md` (раздел 4) и voice-файлов проекта (`about-me.md`, `voice.md`), если они есть.
3. Целевые площадки: по умолчанию **только vk**. Варианты max / telegram / tenchat предлагать НЕ нужно — они в спящем режиме; включать только по явной просьбе пользователя. Типовые связки — в playbook, раздел 1.

## Шаг 2. Прочитать карты
Для каждой выбранной площадки прочитать ПОЛНУЮ карту
`skills/social-media-ru/references/platforms/<slug>.md`.
Выписать рабочие ограничения: лимит длины, разметка, хештеги, ссылки, медиа.
Если карта имеет `confidence: предположение` — пометить вывод как «не верифицировано, проверить перед публикацией».

## Шаг 3. Собрать версии
Для каждой площадки сгенерировать отдельную версию по правилам карты:
- Соблюдать лимиты (сокращать по приоритету: детали → примеры → второстепенные тезисы; крючок и главный вывод сохраняются).
- Убирать неподдерживаемую разметку; приводить хештеги к нужному количеству.
- Менять тон под аудиторию площадки (TenChat — деловой кейс; VK — польза + обсуждение; TG — короткий экспертный пост; MAX — официальный анонс, plain text).
- Версии НЕ должны совпадать дословно между собой (анти-спам). Проверить явно: сравнить первые 2 строки и ключевые абзацы pairwise.

## Шаг 4. Вывод
Для каждой площадки показать блок:

```
### <Площадка> (<путь публикации: API|браузер>)
Длина: N символов (лимит по карте: M)
Хештеги: ...
Медиа: <что приложить>

<финальный текст в code block>
```

Плюс сводная таблица «площадка → длина → статус готовности».

## Шаг 5. Передача в публикацию
Спросить: публиковать сейчас или сохранить черновики.
- vk → `vk-publisher`; telegram → `telegram-publisher`; max/tenchat → `browser-publisher`.
- Публикация только после явного подтверждения текста пользователем.

## Чего не делать
- Не копипастить один текст на все площадки.
- Не выдумывать лимиты, которых нет в карте.
- Не публиковать без подтверждения.

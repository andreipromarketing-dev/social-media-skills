# Telegram — платформенная карта

## 1. Публикация
- **Bot API** (основной путь): `sendPhoto` / `sendMediaGroup` (альбом до 10) / `sendMessage` с параметром `caption`. Бот должен быть админом канала. Токен получается через @BotFather. Готовые интеграции: mcp-telegram (chigwell), python-telegram-bot.
- **Браузер/десктоп**: web.telegram.org или k.telegram.org → канал → поле «Сообщение». Нужен, если пост публикуется от имени владельца канала, а не бота.
- Отложенные посты: в UI — стрелка у кнопки отправки → «Запланировать»; Bot API — только сторонние решалы (cron + self-hosted).
- Быстрая реакция на комментарии: обсуждения канала выносятся в связанный чат (`discuss`-ссылка).

## 2. Форматирование текста
- Markdown в Bot API — ограниченный набор (`parse_mode`: MarkdownV2 или HTML). Надёжнее HTML: `<b>`, `<i>`, `<u>`, `<s>`, `<a href>`, `<code>`.
- В обычном вводе сообщения (не через бота) разметки нет — plain text + эмодзи.
- Хештеги: работают как кликабельные #теги, но это не система продвижения, а навигация по своему каналу. Норма: 1–3 тематических тега.
- Упоминания: `@username`; пересылка сообщений — `/forward` в UI.

## 3. Лимиты
- Сообщение/подпись к медиа: 1024 символа (caption фото/видео), текст сообщения — 4096 символов.
- Длинный текст режется на несколько сообщений или оформляется ссылкой на Telegraph-статью.
- Изображения: до 10 МБ (бот), рекомендуемый размер превью ~1280×720.

## 4. Алгоритм и поведение аудитории
- Хронологическая лента без охватного алгоритма: важнее регулярность и удержание подписчиков, а не «залёт» в рекомендации.
- Хорошо работают: короткие экспертные посты (500–1200 знаков), голосовые-расшифровки, опросы, кружки (видеосообщения).
- Время: ориентир будни 9:00–10:00 и 19:00–22:00 МСК; смотреть статистику канала.

## 5. Чего избегать
- Flood limits Bot API: не более ~20 сообщений/мин в один чат; массовая рассылка новым чатам ведёт к блокировке бота.
- Прямые ссылки на сторонние ресурсы в лоб снижают доверие — лучше нативная подача + ссылка отдельным сообщением.
- Удаление/редактирование поста заметно подписчикам в обсуждениях — проверять текст до публикации.

## 6. Отличия от других площадок проекта
- vs VK: здесь нет хештег-продвижения и «под кат»; caption короче — 1024 знака против ~2000+ у ВК.
- vs MAX: тот же формат «канал», но MAX не даёт такой зрелый Bot API — публикация преимущественно через браузер.
- vs TenChat: Telegram — про быстрый контакт с текущей аудиторией, а не про поиск новой.

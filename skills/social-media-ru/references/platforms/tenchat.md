# TenChat — платформенная карта

> Позиционирование: деловая соцсеть (аналог LinkedIn в РФ). Публичного API
> для публикации нет → путь автоматизации — браузерный скилл.

## 1. Публикация
- Веб-версия: tenchat.ru (вход по телефону/почте). Поле «Создать пост».
- Форматы: посты с фото/видео, лонгриды, «вакансии/предложения» (бизнес-блоки).
- Медиа: загрузка через UI; точные лимиты замерить при браузерном прогоне.

## 2. Форматирование текста
- Plain text + эмодзи; Markdown не поддерживается (проверить актуальное состояние редактора).
- Хештеги: важны — тематические теги (#маркетинг, #автоматизация…) влияют на показы в подборках. Норма: 3–7 релевантных тегов.
- Упоминания: @имя пользователя работают.

## 3. Лимиты
- Длина поста и поведение «под кат» — замерить в браузере (ориентир: длинные посты сворачиваются, первые ~2 строки — витрина).

## 4. Алгоритм и поведение аудитории
- Деловая аудитория: полезно — кейсы, экспертные разборы, истории внедрения, цифры.
- Продвижение через нетворкинг: взаимные комментарии и подписи экспертов усиливают охват (аналог LinkedIn-механик).
- Хорошо индексируется Яндексом — посты могут давать входящий поиск.

## 5. Чего избегать
- Рекламных лобовых постов без пользы — низкий отклик, деловая аудитория чувствительна.
- Продающих ссылок в первых строках.
- Копипаста один-в-один из других площадок без адаптации под деловой тон.

## 6. Отличия от других площадок проекта
- vs VK/TG: здесь важен личный бренд эксперта и нетворкинг, а не охват сообщества.
- Тон — самый «деловой» из четырёх площадок; ближе всего к исходным LinkedIn-скиллам форка.

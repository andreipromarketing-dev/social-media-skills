# ВКонтакте — платформенная карта

## 1. Публикация

### Сообщество (паблик/группа) — основной режим
- **API**: метод `wall.post` (токен сообщества, права `wall`). Для картинки сначала `photos.getOwnerPhotoUploadServer` / `photos.getWallUploadServer`, затем `photos.saveOwnerPhoto` / `photos.saveWallPhoto`, в `wall.post` передаётся `attachments=photo<owner_id>_<mid>_<access_key>`.
- **Браузер**: vk.com → сообщество → поле «Написать сообщение…». Подходит, когда API-токена нет или нужен сложный пост (карусель, опрос, отложенный пост).
- Отложенные посты: в браузере — кнопка стрелки у «Опубликовать»; через API — параметр `publish_date` (unixtime).
- Мультимедиа: фото (до 10 в записи), видео (`video.add`), документы, ссылки (автоматический сниппет).

### Личный профиль
- Токен пользователя с правом `wall` позволяет постить на свою стену. Ограничения строже анти-спам, чем у сообществ.

## 2. Форматирование текста
- Разметки как таковой нет: plain text + эмодзи + переносы строк.
- Внутренние ссылки: `[club12345|Название сообщества]`, `[id12345|Имя]`, `@publicname`.
- Хештеги: работают, синтаксис `#тег` (без пробелов, регистр не важен). Рекомендация практиков: 3–5 штук, лучше в конце поста; избыток снижает охват.
- Жирный/курсив в обычных записях стены НЕ поддерживаются (только в статьях через конструктор/редактор статей).

## 3. Лимиты
- Текст записи на стене: до ~10 000 символов; длинный текст автоматически прячется «под кат» примерно после ~1800–2500 символов (точное значение проверить в браузере).
- Заголовок статьи: отдельный формат (редактор статей), длинный лонгрид лучше оформлять статьёй.
- Хештеги: технически без жёсткого лимита, практически >10 выглядят как спам.

## 4. Алгоритм и поведение аудитории
- Аудитория РФ, русскоязычная; хорошо работают: полезные лонгриды-статьи, посты с живым фото, опросы, обсуждения.
- Важны первые часы: лайки/комментарии/повторы поднимают показ в ленте сообщества.
- Время публикации: будни ~9:00–11:00 и 18:00–21:00 по МСК (проверить по своей статистике).
- «Мини-карточки» и затекстовые картинки повышают CTR в ленте.

## 5. Чего избегать
- Анти-спам: одинаковые тексты с разных аккаунтов, резкие всплески публикаций, много внешних ссылок в одном посте.
- Провоцирование репостов («репост = …») пессимизируется.
- Ссылки на сторонние сайты снижают охват — ссылку лучше давать в комментарии или в тексте без сокращателей.

## 6. Отличия от других площадок проекта
- vs Telegram: здесь есть лента-алгоритм и хештеги; текст без Markdown.
- vs MAX: ВК поддерживает длинные посты и статьи; MAX — короткие посты.
- vs TenChat: ВК — про аудиторию и охваты, TenChat — про деловые связи.
